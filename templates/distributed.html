Worker setup

For a local demo, run two workers on the same computer. No other devices are needed. This tests HTTP communication, not performance across separate computers. The Analyzer works without workers.

Open three terminals in the Wordly project folder. Install the project dependencies first. If sample data is missing, run python -m research.generate_dataset.

1. Start worker 1

source .venv/bin/activate
export WORDLY_TOKEN="wordly-local-demo-test-secret"
python -m distributed.worker --host 127.0.0.1 --port 8765

2. Start worker 2

source .venv/bin/activate
export WORDLY_TOKEN="wordly-local-demo-test-secret"
python -m distributed.worker --host 127.0.0.1 --port 8766

3. Start Wordly

Stop Wordly with Control + C first.

source .venv/bin/activate
export WORDLY_TOKEN="wordly-local-demo-test-secret"
export WORDLY_WORKERS="http://127.0.0.1:8765,http://127.0.0.1:8766"
python app.py

4. Run a comparison

Keep both workers running. Refresh this page, click Check connections, then choose a dataset and click Analyze. If offline, check the ports and token. Press Control + C in each terminal when finished.

The example token is for local testing only. For other computers, use a private shared token and a trusted network. HTTP is unencrypted. Never send sensitive data or expose worker ports publicly.
